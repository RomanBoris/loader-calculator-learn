# Loader Calculator

Android-приложение для учёта работы грузчиков на складе. Позволяет фиксировать
погрузки/выгрузки за смену и автоматически рассчитывать процент выработки.

> **Примечание:** Это мой первый учебный проект. Код рабочий, полностью идея не реализована
> и будет дорабатываться.

## Возможности

- Учёт трёх типов работ:
  - **20Т** — отгрузка фур (20 тонн)
  - **12/7/5** — отгрузка мини-машин
  - **ВЫГР** — выгрузка (приёмка товара)
- Учёт замороженных палет (ЕО «Мороз») с повышающим коэффициентом
- Автоматический расчёт процента выработки «Сделано: X%»
- Добавление записей через кнопки внизу, редактирование по долгому нажатию, удаление
- Сохранение текущей смены в историю одной кнопкой (с подтверждением)
- История смен — карточки с датой, длительностью, итогами по каждому типу и процентом
- Настройка длительности смены (карандаш рядом с заголовком, по умолчанию 11 часов)
- Все данные хранятся локально (Room + DataStore)

## Формула расчёта

```
нормо-часы = (ЕО_20Т / 25) + (ЕО_мини / 20) + (ЕО_выгрузка × 0.06) + (ЕО_мороз × 0.02)

выработка % = (нормо-часы / длительность_смены) × 100
```

*Длительность смены задаётся в настройках и сохраняется между сессиями.*

## Требования

- Android 7.0+ (API 24)
- Android Studio Hedgehog или новее

## Сборка и запуск

1. Клонируйте репозиторий:

4. Запустите на эмуляторе или устройстве
